# 🎡 عالم رقية — النسخة الأولى (V1)

لعبة عربية مجانية قدر الإمكان للعب الخاص بين بابا ورقية على موبايلين من مكانين مختلفين. الألعاب: 🎨 الرسم والتخمين، 🃏 كروت الذاكرة، ❌⭕ إكس أو.

**مهم:** الملفات جاهزة، لكن اللعبة ليست متصلة بالإنترنت فعليًا حتى تُنشئ مشروع Firebase بنفسك وتضع إعداداته وتنشر الملفات. لا يمكن للمطوّر ضمان عمل الاتصال بين جهازين دون اختبار Firebase الخاص بك.

## الملفات الموجودة

- `index.html`: الصفحة الرئيسية.
- `style.css`: الألوان والتصميم المتجاوب.
- `app.js`: إنشاء الغرف، المزامنة، وقواعد اللعب.
- `firebase-config.js`: إعدادات مشروع Firebase الخاص بك؛ استبدل الكلمات `PASTE_...`.
- `database.rules.json`: قواعد الوصول لقاعدة البيانات. **لا تنشر قاعدة البيانات بوضع Test mode.**
- `manifest.webmanifest` و`icon-192.png` و`icon-512.png`: أيقونة وإعدادات إضافة التطبيق للشاشة الرئيسية.

## الخطوة 1 — أنشئ Firebase مجانًا من الموبايل

1. افتح https://console.firebase.google.com من Chrome على موبايلك، وسجّل دخولك بحساب Google الذي تختاره. لو القوائم مش ظاهرة فعّل **Desktop site** من قائمة Chrome.
2. اضغط **Create a project**، وسمّه مثلًا `alam-roqaya`. عطّل Google Analytics لأنه غير مطلوب لهذه اللعبة، ثم أكمل.
3. من **Project Overview > Project settings > Your apps** اختار رمز الويب `</>` ثم سجل تطبيق ويب باسم `Alam Roqaya`. لا تحتاج تفعيل Firebase Hosting لأننا سنستخدم GitHub Pages.
4. انسخ كائن الإعدادات `firebaseConfig` الذي يظهر لك (يشمل `apiKey`, `authDomain`, `projectId`, `appId`، وقد لا يشتمل على `databaseURL` حتى إنشاء قاعدة البيانات). 
5. من **Build > Realtime Database > Create Database**، اختار موقعًا متاحًا، ثم **Start in locked mode** إن ظهر الاختيار. ابق على خطة **Spark** المجانية؛ لا ترقي إلى Blaze.
6. انسخ **Database URL** من صفحة Realtime Database؛ مثال شكلي فقط: `https://YOUR-PROJECT-default-rtdb.REGION.firebasedatabase.app/`. استخدم القيمة الفعلية لمشروعك.
7. من **Build > Authentication > Get started > Sign-in method > Anonymous** فعّل المصادقة المجهولة ثم **Save**.
8. افتح **Realtime Database > Rules**، واحذف النص الحالي والصق كامل محتوى ملف `database.rules.json`، ثم اضغط **Publish**. قواعد الملف تسمح بإنشاء غرف عشوائية من 8 رموز وتربط عضويتها بمعرّفات الحسابات المجهولة. اختبر القواعد قبل مشاركة الرابط مع آخرين.

## الخطوة 2 — ضع إعدادات Firebase داخل ملف config

افتح `firebase-config.js` في محرّر GitHub بعد رفعه؛ واستبدل **القيم** بالقيم الحقيقية التي نسختها. مثال شكلي **ليس صالحًا للتشغيل**:

```js
export const firebaseConfig = {
  apiKey: "YOUR_REAL_API_KEY",
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  databaseURL: "YOUR_EXACT_REALTIME_DATABASE_URL",
  projectId: "YOUR_PROJECT_ID",
  appId: "YOUR_REAL_APP_ID"
};
```

ليس مطلوبًا أن تتطابق قيم مشروعك مع المثال. إعدادات Firebase للويب ليست كلمة سر، لكن **قواعد قاعدة البيانات** هي التي تفرض صلاحيات الوصول. لا تضع كلمات مرور أو رموز حساباتك في GitHub.

## الخطوة 3 — انشر اللعبة على GitHub Pages من الموبايل

1. افتح https://github.com وسجّل دخولك. اعمل **New repository** باسم `alam-roqaya` واختر **Public** (شرط GitHub Pages في الخطة المجانية).
2. من المستودع اضغط **Add file > Upload files**. بعد **فك ضغط ZIP على الموبايل**، ارفع جميع الملفات التسعة من داخل مجلد `alam_roqaya_v1` مباشرةً إلى **جذر** المستودع، وليس ملف ZIP نفسه. لو زر Upload files غير ظاهر استخدم **Desktop site** في Chrome.
3. افتح ملف `firebase-config.js` داخل GitHub ثم اضغط زر التحرير (القلم)، وألصق القيم الحقيقية بدل `PASTE_...`، ثم **Commit changes**.
4. من المستودع افتح **Settings > Pages**. تحت **Build and deployment** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
5. رابط اللعبة يصبح بالشكل `https://USERNAME.github.io/alam-roqaya/` (استبدل USERNAME باسم GitHub الفعلي). افتحه بعدما يظهر GitHub رسالة نشر الموقع. إن ظهر 404 تأكد أن `index.html` موجود في جذر المستودع، وراجع إعدادات Pages.
6. لا تشارك رابط المستودع أو غرفة اللعب علنًا على أساس أنها بيانات خاصة: ملفات GitHub Pages عامة؛ الخصوصية هنا لغرفة اللعب المحمية بقواعد Firebase والكود السري، **وليست خصوصية رابط الموقع**.

## الخطوة 4 — اختبر بين موبايلين

1. من موبايل بابا: افتح رابط GitHub Pages، واضغط **بابا: اعمل غرفة جديدة**.
2. اضغط **نسخ رابط الدعوة**؛ سيحتوي الرابط على `#room=XXXXXXXX`. ابعته لرقية بشكل خاص.
3. من موبايل رقية: افتح نفس الرابط في Chrome واضغطي **رقية: ادخلي الغرفة**؛ الرابط يملأ الكود تلقائيًا. يمكن أيضًا كتابة كود الغرفة يدويًا.
4. بعد ظهور **رقية متصلة** عند بابا، يختار بابا إحدى الألعاب. المفروض تظهر نفس الشاشة فورًا عند الطرفين.
5. اختبر نقل دور الذاكرة، وضع علامة في إكس أو، ورسم خط من بابا ومشاهدته عند رقية.
6. من قائمة Chrome > **Add to Home screen** (أو Install app إن ظهرت) لتشغيل اللعبة من أيقونتها.

## طريقة اللعب

- **الرسم والتخمين:** بابا يرسم أولًا، ورقية تختار الإجابة من 3 صور بدل الكتابة. الإجابة من أول محاولة = نقطتان، والثانية/الثالثة = نقطة. اضغط **الرسمة اللي بعدها** لتبديل الرسّام.
- **كروت الذاكرة:** كل واحد يفتح كارتين في دوره. زوج مطابق = نقطة ودور إضافي، وغير مطابق = ينتقل الدور بعد 1.35 ثانية. هناك 4 أزواج في الجولة.
- **إكس أو:** بابا ❌ ورقية ⭕. الفوز = 3 نقاط، والتعادل = نقطة لكل واحد.
- **العودة للمدينة:** بابا فقط يتحكم في اختيار اللعبة أو بدء جولة جديدة؛ النقاط الإجمالية تظل موجودة داخل الغرفة نفسها.

## الخصوصية والحدود الحالية

- الغرفة لها **رمز عشوائي من 8 محارف** ويستطيع الانضمام إليها شخص ثانٍ فقط. من يعرف الرمز قد يصل إلى بيانات غرفة غير مكتملة ويشغل المقعد الثاني؛ أرسل الدعوة بشكل خاص.
- خدمة Firebase تستخدم معرّفات مستخدمين مجهولة. لا تُطلب أسماء حقيقية أو صور أو موقع أو بريد إلكتروني من الطفلة، ولا يوجد دردشة عامة أو ميكروفون أو كاميرا أو إعلانات.
- من يمسح بيانات المتصفح أو يستخدم المتصفح الخفي قد يفقد معرّف Firebase المجهول وبالتالي إمكانية إعادة الدخول إلى غرفة مكتملة؛ أنشئ غرفة جديدة في هذه الحالة.
- الاتصال يحتاج إنترنت فعليًا. الرسم يُزامن كخطوط قصيرة، وليس صوتًا أو بث فيديو. **لم يُختبر الاتصال مع حساب Firebase حقيقي أو موبايلين في هذه النسخة المُسلّمة.**
- الغرف القديمة لا تُحذف تلقائيًا، وتبقى البيانات محفوظة في مشروع Firebase الخاص بك إلى أن تحذفها من وحدة التحكم. يُفضّل حذف الغرف القديمة دوريًا. لا ترقِّ المشروع إلى خطة مدفوعة دون قصد.
- قاعدة البيانات لا تمنع كل أنواع إساءة الاستخدام أو التلاعب بالنقاط من مستخدم متمرّس لديه صلاحية الغرفة؛ النسخة مصممة للعب العائلي الودّي لا للمنافسات الرسمية. اختبرها قبل استخدامها على نطاق أوسع.
- إن واجهت `permission_denied`: تأكد أنك نشرت **قواعد Realtime Database** الصحيحة على **نفس قاعدة البيانات** التي يشير لها `databaseURL`، وفعلت Anonymous Authentication. لا تجعل القواعد عامة `true` لحل المشكلة.
