# مدرسة وعالم رقية — Merge M1

النسخة المدمجة الأولى:
- بوابة مدرسة رقية بالصورة الجديدة.
- طرقة المدرسة التفاعلية.
- اللغة العربية بمحتوى مدرسة رقية الحالي.
- الحساب والإنجليزي والقرآن كأقسام "قريبًا".
- عالم رقية الحالي بكل الألعاب.
- مكالمات V21 ووضع الإنترنت الضعيف جدًا واللاسلكي واختيار أجهزة الصوت/البلوتوث.
- زر الاتصال متاح من بوابة المدرسة بمجرد دخول رقية لنفس الغرفة.
- بابا فقط يتحكم في اختيار المادة أو الانتقال لعالم رقية.
- المكالمة تظل في الصفحة العليا عند فتح العربي.

ارفع الملفات والمجلدات إلى جذر مستودع Alaam-Roqaya مع الحفاظ على:
index.html
app.js
style.css
firebase-config.js
assets/
school/

لا تحذف manifest.webmanifest أو الأيقونات الموجودة بالفعل في المستودع.
