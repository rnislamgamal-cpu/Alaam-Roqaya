# M2 إصلاحات الدمج

هذه النسخة Patch فوق Merge M1 الحالي.

ارفع إلى root في GitHub:
- index.html (Replace)
- m2-fix.css (ملف جديد)

مهم جدًا لتشغيل مدرسة رقية:
رفع database.rules.json إلى GitHub وحده لا يغيّر Firebase.
افتح Firebase Console > Realtime Database > Rules
وانسخ محتوى database.rules.json كاملًا ثم Publish.

الإصلاحات:
- الصور تظهر كاملة بدون Crop / Zoom على الموبايل والتابلت.
- الحفاظ على نسبة الصور الأصلية 1536×1404.
- شريط المكالمة لا يغطي الصورة.
- رسالة نسخ الدعوة أصغر.
- مناطق الضغط في الطرقة شفافة ولا تضيف أسماء فوق الصورة.
- كروت المواد/عالم رقية تظهر أسفل الصورة بدل تغطيتها.
- إضافة قواعد studyRoomsV3 المطلوبة لمدرسة رقية.

لا تستبدل app.js أو ملفات school في هذا الـPatch.
