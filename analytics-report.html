🎡 تقرير استخدام الألعاب

لوحة محلية لحساب عدد الغرف والجولات. تُعالِج ملف Firebase داخل متصفحك فقط؛ لا ترفعه إلى الموقع أو تشاركه مع أحد.

🔒 مهم للخصوصية: ملف التصدير الخام من Firebase قد يحتوي أسماء أطفال ومعرّفات ورسومات. اختَر الملف هنا فقط، ولا تنشره على GitHub أو ترسله بالمحادثة. اللوحة تعرض المجاميع فقط، ولا تحفظ الملف أو تبعثه إلى أي خادم. لا تستخدم أي إضافات متصفح غير موثوقة أثناء فتح بياناتك.

١. اختَر فترة التقرير وملف التصدير

من Firebase Console ← Realtime Database ← Data ← Export JSON. اختر تصدير جذر البيانات. لا تضع الملف في مستودع GitHub العام. ابدأ فترة قياس الألعاب من تاريخ نشر V6؛ زيارات الموقع الأقدم موجودة في Cloudflare فقط.

٢. ملخص الفترة

«الغرف» ليست أسرًا فريدة، و«الأيام النشطة» أيام ظهر فيها نشاط في غرفة واحدة على الأقل. الغرف التي وُجدت قبل V6 ليست جزءًا من إجمالي الغرف الجديدة.
