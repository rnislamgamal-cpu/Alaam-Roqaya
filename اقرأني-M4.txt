# M4 — التحديث الشامل لعالم رقية

النسخة دي تشمل التعديلات المتفق عليها:
- ترتيب واجهة عالم رقية ونقل كود الغرفة لآخر الألعاب.
- تكبير كروت بابا ورقية وإظهار نقطة الحالة فقط.
- ضغط المساحات في كل الألعاب.
- كروت ألعاب جديدة وأكثر حيوية.
- لعبة مين المختلف أصعب بفروق دقيقة.
- اختيار عدد كلمات الإنجليزي (10/20/30/40...).
- الحساب RTL.
- بازل مستقل لكل لاعب مع 4/10/20/50 قطعة وصور البازل الجديدة.
- صور التلوين الجديدة الـ13 مع تلوين بالضغط داخل المساحات.
- نافذة أجهزة المكالمة قابلة للإغلاق والضغط خارجها يغلقها.
- الرسائل المؤقتة تختفي تلقائيا.

ملفات الاستبدال في root:
- index.html
- app.js
- m4-fix.css (جديد)

الفولدرات الجديدة:
- assets/coloring/
